# Sagar-Web-Package

Interactive 3D brochure website for **Sagar Pathak — Web Development Packages**.

Stack: **React + TypeScript + Vite + Three.js (@react-three/fiber/drei) + Framer Motion + Tailwind CSS**.

## Content (1:1 with PDF)

- `01` Hero — Websites built to work · ₹10,000 → ₹35,000 · Custom apps quoted separately
- `02` Package overview — Starter ₹10k / Business ₹15k / Professional ₹22k / Business Pro ₹35k
- `03` Common foundation (6 items) + entry packages detail
- `04` Growth packages + when Business Pro makes sense
- `05` Infrastructure — domain / hosting / DB-cloud / third-party (all client-paid)
- `06` Comparison table (15 rows)
- `07` Commercial terms (5) + Custom app Discuss → Scope → Quote
- `08` Contact — GitHub / LinkedIn / Instagram + infrastructure note + Thank you

Portrait used: `public/portrait.png` (same as `assets/SagarPortfolioImage.png`).
Downloadable brochure: `public/Sagar_Pathak_Web_Development_Packages_INTERACTIVE.pdf` (same file as given).
